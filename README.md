One funny single line a hopeless tech support agent says to a desperate
customer, written for the [Have You Tried Turning It Off?](https://make.fun/bounty/u-motasimfuad-have-you-tried-turning-it-off-154a938b)
competition on make.fun.

## How it works

`main.py` (Python 3.13) writes exactly one line to `/output/entry.txt`:

> I've escalated your ticket to a specialist. It's me, in a different hat.

The program is deterministic — it writes the same bytes on every run.

## Run it

```sh
python3 main.py
```
